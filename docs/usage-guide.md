# Data Input Formats

The timeseries-svg library automatically normalizes various input formats. Use the format that best matches your data source.

## List of Dicts (Standard Format)

Recommended for most use cases. Uses `d` for date and `c` for close/value.

```json
[
  {"d": "2024-01-01", "c": 100.0},
  {"d": "2024-01-02", "c": 102.5},
  {"d": "2024-01-03", "c": 101.2},
  {"d": "2024-01-04", "c": 105.0},
  {"d": "2024-01-05", "c": 103.8}
]
```

## List of Lists

Each inner list is `[date, value]`:

```json
[
  ["2024-01-01", 100.0],
  ["2024-01-02", 102.5],
  ["2024-01-03", 101.2],
  ["2024-01-04", 105.0]
]
```

## Dict with Date Keys

Date strings as keys, values as the data:

```json
{
  "2024-01-01": 100.0,
  "2024-01-02": 102.5,
  "2024-01-03": 101.2,
  "2024-01-04": 105.0
}
```

## Simple Value List

Auto-generates dates as "day-0", "day-1", etc. Best for sparklines where dates don't matter:

```json
[100.0, 102.5, 101.2, 105.0, 103.8, 107.0]
```

## Custom Keys

If your data uses different key names, specify them:

```json
[
  {"date": "2024-01-01", "price": 100.0},
  {"date": "2024-01-02", "price": 102.5},
  {"date": "2024-01-03", "price": 101.2}
]
```

Use with:
```python
renderer.render(data, date_key="date", value_key="price")
```

## Nested Format (JSONB from databases)

Common format for database JSONB storage - the library extracts the array automatically:

```json
{
  "history": [
    {"d": "2024-01-01", "c": 100.0},
    {"d": "2024-01-02", "c": 102.5},
    {"d": "2024-01-03", "c": 101.2}
  ]
}
```
